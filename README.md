# Watch E-Commerce Website

A front-end website built to showcase and browse a curated collection of watches.

## Overview
This project focuses on front-end web development fundamentals — building a clean, navigable interface for displaying products using HTML, CSS, and JavaScript. It covers page layout, responsive design, and basic interactivity for browsing a product catalog.

## Features
- Watch product listings with images and details
- Responsive layout for different screen sizes
- Clean navigation between pages/sections
- Styled using custom CSS

## Tech Stack
- **HTML** – page structure and content
- **CSS** – styling and layout
- **JavaScript** – interactivity and dynamic behavior

## Purpose
Built as an academic project to practice front-end design principles, including layout structuring, responsive design, and basic client-side scripting.
